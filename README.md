# Privacy Policy - Watchers

_Last updated: 8 October 2026_

Watchers is a private, self-hosted automation run by its owner. It is not a
public service and is not offered to other users.

## What it does

It signs in to the owner's own Google Account solely to:

- read spreadsheets that the owner has shared with it; and
- convert the owner's own uploaded Excel files into Google Sheets and copy the
  resulting worksheets into the owner's own spreadsheets.

## What is accessed

Only files and spreadsheets owned by, or explicitly shared with, the owner's
Google Account. The application requests the narrow `spreadsheets` and
`drive.file` scopes. It cannot see or modify any file the owner has not
explicitly used with it.

## What is collected or shared

Nothing. The application does not collect, store, transmit or share personal
data with any third party. It runs locally (on the owner's own machine or Docker
host), keeps its credentials locally, and stores no user data outside the
owner's own Google Drive and spreadsheets.

## Third parties

No data is sent to any third party. Google APIs are used solely to perform the
operations above under the owner's own account.
